# Database schema v1 (frozen at G0)

PostgreSQL 16 with `pgvector` (image `pgvector/pgvector:pg16`), plus `pg_trgm` and `unaccent`.
The executable DDL is **`contracts/db_schema.sql`**. It is the contract. This file explains it.

- **T1:** the first Alembic migration (`0001_initial`) must produce exactly this schema. It can just
  run `db_schema.sql` (`op.execute(open(...).read())`). Later changes need a new migration, a matching
  edit to `db_schema.sql` and a `CHANGELOG.md` entry.
- **Only the backend writes to PostgreSQL.** Adapters and services go through the backend API.
- Seed data: `scripts/seed/*.json` → `scripts/reset_demo.sql` (generated by
  `scripts/seed/generate_seed.py`). Load it with `scripts/reset_demo.sh`.

## Conventions

| Item | Rule |
|---|---|
| IDs | `uuid` (v4) for operational rows; readable text ids for reference data (`br-ngozi`, `business_loan`, `kb-…`, `agent-01`) |
| Time | `timestamptz`, stored and returned in UTC |
| Money | `bigint` FBu, no decimals |
| Phone | `+257XXXXXXXX` (CHECK constraint) |
| Language | `fr`, `en`, `rn` (CHECK constraint) |
| Multilingual text | `jsonb` `{"fr": …, "en": …, "rn": …}`, all three keys required |
| Fictional data | Reference tables have `fictional boolean NOT NULL DEFAULT true CHECK (fictional)`, so no real record can be inserted by mistake |

## Tables

PRD data model, plus the tables needed by the contracts (`kb_articles`, `agents`,
`card_block_requests`, `files`).

| Table | Purpose | Key columns |
|---|---|---|
| `customers` | Synthetic customers | `id`, `full_name`, `phone` (unique), `account_number` (11 digits, unique), `province`, `town`, `language`, `date_of_birth`, `pin_hash` (argon2id), `failed_attempts`, `locked_until` |
| `cards` | Customer cards | `id`, `customer_id`, `last4`, `card_type`, `status` (active/blocked/expired), `blocked_at`, `block_reason`, `block_reference` (BLK-YYYY-NNNNN) |
| `branches` | Branch hours and contacts (F8) | `id`, `name`, `province`, `town`, `address`, `phone`, `hours` jsonb per weekday (`null` = closed), `services` |
| `loan_products` | Loan products (F6) | `id`, `name` / `description` / `requirements` (jsonb fr/en/rn), `annual_rate_pct`, `min_amount`, `max_amount`, `min_term_months`, `max_term_months` |
| `kb_articles` | Knowledge base source, one row per topic and language | `id`, `topic`, `intent`, `lang`, `title`, `body` |
| `kb_chunks` | RAG units (F4) | `id`, `article_id`, `source`, `lang`, `chunk_index`, `text`, `embedding vector(768)`, `tsv` (generated, `simple` config) |
| `agents` | Demo agents and supervisor | `id`, `name`, `languages`, `role` |
| `calls` | One per conversation on any channel; `id` = conversation id | `phone`, `customer_id`, `channel`, `session_key`, `language`, `status`, `resolved_by`, `model`, `last_intent`, `urgency`, `frustration`, `handoff_reason`, `summary`, `claimed_by`, `started_at`, `queued_at`, `claimed_at`, `ended_at` |
| `call_turns` | Transcript | `call_id`, `message_id` (idempotency), `speaker`, `agent_id`, `text`, `lang`, `intent`, `confidence`, `frustration`, `attachments`, `model_used`, `reply_json`, `ts` |
| `tickets` | Complaints (F7) | `number` (TCK-YYYY-NNNNN), `call_id`, `customer_id`, `phone`, `category`, `urgency`, `summary`, `description`, `status`, `lang`, `assigned_to` |
| `sessions` | Orchestrator state per session (PRD: phone, state, context_json) | `session_key` (phone, USSD session or conversation id), `call_id`, `phone`, `state`, `context_json` |
| `card_block_requests` | Pending confirmations between verify and confirm (5 min) | `id` (= confirmation_id), `card_id`, `call_id`, `reason`, `expires_at`, `confirmed_at` |
| `model_events` | Model switches and fallbacks (F20, F21) | `call_id`, `requested_model`, `used_model`, `capability_needed`, `reason`, `fallback_path`, `notice`, `lang`, `ts` |
| `files` | Uploaded images and audio, TTS audio, generated PDFs | `id`, `kind`, `mime`, `size_bytes`, `path`, `call_id` |

Sequences: `card_block_ref_seq` → `BLK-<year>-<5 digits>`, `ticket_number_seq` →
`TCK-<year>-<5 digits>`. The seed sets them past the seeded references.

## Rules that the schema alone does not enforce

1. **Security:** `pin_hash` is argon2id (`argon2-cffi`, default parameters). A PIN or date of birth is
   never stored in `call_turns.text` (store `••••`), `sessions.context_json`, logs or any LLM prompt.
   After 3 failed checks on a customer, set `locked_until = now() + 15 min` and hand off (reason `identity_failed`).
2. **Queue claim:** `SELECT … FROM calls WHERE id = :id AND status = 'queued' FOR UPDATE SKIP LOCKED`.
   No row → 409.
3. **Events:** after each write that maps to a WebSocket event, `NOTIFY kabangutsi_events, '<json>'`.
   The payload is the full event from `ws_events.json`. If it would exceed 7900 bytes, send
   `{"type": …, "id": …, "ref": "<table>:<id>"}` and let the hub load the row.
4. **Embeddings:** `kb_chunks.embedding` is NULL in the seed. The backend fills missing embeddings at
   start-up with `nomic-embed-text` (768 dimensions). Hybrid search = cosine similarity + `ts_rank`
   on `tsv` + `similarity(text, q)` from pg_trgm, all filtered by `lang`.
5. **Stats** (`ws_events.json#/$defs/Stats`) are computed from `calls` and `tickets` for the current
   day in Africa/Bujumbura time (UTC+2).
6. **Session reuse:** for SMS and WhatsApp, an inbound message reuses the open call with the same
   `(channel, session_key)` if its last turn is less than 30 min old. Otherwise a new call starts.
